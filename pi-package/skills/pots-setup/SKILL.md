# Set up Pots

Pots is not a pi extension. It is its own program, built on pi-durable, that runs AI coworkers in team chats. This skill only helps you set it up for your person.

1. Read the setup guide that comes with this package: [docs/for-agents.md](../../../docs/for-agents.md). If that file is not there, read https://github.com/Crokily/pi-durable-bot/blob/main/docs/for-agents.md.
2. Do what it says. It tells you what to ask your person, how to install Pots (`npm install -g pi-durable-bot`), how to make the bot, and how to check that the bot answers.

The bot gets full control of the computer it runs on, with no approval step. Tell your person this before you install, and suggest a computer or VM of its own.

More: https://github.com/Crokily/pi-durable-bot
